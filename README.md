# Atelier 
### Fashion Retail Inventory Management (Java)

## Overview

Atelier is a console-based fashion retail inventory management application developed in Java as a personal summer learning project.

I created Atelier to strengthen my understanding of Java fundamentals, object-oriented programming, and file handling while exploring a practical application in the retail industry.

## Features

- **View Inventory:** Display available products and their stock information.
- **Process Sales:** Sell products and update inventory quantities.
- **Restock Products:** Increase inventory quantities for existing items.
- **Add Products:** Register new products with relevant details.
- **Delete Products:** Remove products from inventory.
- **Low-Stock Monitoring:** Identify products that may require replenishment.
- **File Persistence:** Save and load inventory data using a text file.

## Technologies & Concepts

## How to Run

1. Download or clone the repository.
2. Open the Java source files in IntelliJ IDEA or another compatible Java environment.
3. Run `Main.java`.
4. Follow the console menu to manage inventory.

The application uses `inventory.txt` to store inventory information.
